# Marta Green Lake СӨХ - Нэгдсэн Цахим Портал

Marta Green Lake хотхоны Сууц Өмчлөгчдийн Холбоо (СӨХ)-ны оршин суугчид болон захиргаанд зориулсан цахим систем.

## Гол боломжууд

### 1. Оршин суугчдын хэсэг
* **Нүүр хуудас (`/`):** Онцгой сэрэмжлүүлэг, 24/7 түргэн тусламжийн дугаарууд (СӨХ дарга, жижүүр, сантехникч, цахилгаанчин, лифт) руу шууд залгах.
* **Төлбөр шалгах (`/bills`):** Тоотоор сарын хураамж, өмнөх үлдэгдэл шалгах, дансны мэдээлэл хуулах, төлбөрийн баримтын зураг илгээх.
* **Цахим санал асуулга (`/polls`):** Хотхоны тохижилт, аюулгүй байдлын шийдвэрт тоотоороо санал өгөх (1 тоот = 1 санал).
* **Автомашин & Зогсоол (`/parking`):** Улсын дугаараар эзнийг хайх, гарц хаасан үед шууд залгах, шинэ машин бүртгүүлэх.
* **Зарлал, сэрэмжлүүлэг (`/announcements`):** Дулаан, ус, цахилгаан, цэвэрлэгээний албан зарууд.
* **Санал хүсэлт, гэмтэл (`/requests`):** Сантехник, цахилгааны эвдрэлийн дуудлага өгөх, явц шалгах (`REQ-101`).
* **Ил тод тайлан (`/reports`):** Сар бүрийн орлого, зарлагын нээлттэй тайлан ба дүрэм журам.

### 2. СӨХ-ийн Админ удирдлага (`/admin`)
* **Админ нууц код:** `admin123`
* **Төлбөрийн удирдлага:** Бүх тоотуудын төлөлт хянах, 1 товшилтоор "Төлсөн" болгох, Excel татах.
* **Банкны хуулгаар автомат тулгагч:** Хаан, Голомт банкны хуулгын текстийг хуулж тавихад тоотууд болон мөнгөн дүнг автоматаар таньж баталгаажуулах.
* **Ирсэн баримтууд:** Оршин суугчдын илгээсэн төлбөрийн баримтын зургийг шалгаж, нэг товшилтоор баталгаажуулах.
* **Санал асуулгын удирдлага:** Шинэ санал асуулга үүсгэх, хаах.
* **Автомашины бүртгэл:** Бүртгэлтэй бүх машины мэдээллийг хянах, Excel татах.
* **Зарлал & Дуудлага:** Зарлал нийтлэх, ирсэн дуудлагыг шийдвэрлэх.
* **Тохиргоо:** СӨХ-ийн нэр, утасны дугаарууд, данснуудыг засах.

## Технологи
* **Framework:** Next.js 14 (App Router)
* **Frontend:** React, TypeScript, Tailwind CSS, Lucide Icons
* **Database / Storage:** Local JSON Data Store (`data/db.json`)

## Ажиллуулах заавар

```bash
# Сангуудыг суулгах
npm install

# Хөгжүүлэлтийн горимд эхлүүлэх
npm run dev

# Продакшн build хийх & эхлүүлэх
npm run build
npm run start
```

Хөтөч дээрээ [http://localhost:3000](http://localhost:3000) хаягаар орно.
